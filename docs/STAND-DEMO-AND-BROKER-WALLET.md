## Что исправлено

Обычная отправка рублей брокеру и завершение криптоприхода больше не включают
`demoTransfers`. Интерфейс получает разрешение на DEMO от сервера, по умолчанию
оно выключено. Кнопки DEMO и засев тестовых сделок без разрешения недоступны.

Синтетические переводы работают только при **`STAND_ALLOW_DEMO=1`** в окружении
изолированного автотестового сервера. На grusha-new флаг отсутствует — это проверено
через Railway API. Без флага сервер отвергает DEMO-вебхуки (403), DEMO-проверку
транзакции и внесение синтетических денег через сохранение доски. Нельзя включить
режим из браузера, выдать старый неподвязанный DEMO-приход за новый реальный или
закрыть сделку по сохранённым DEMO-подтверждениям с активным ошибочным флагом.
Существующие автотесты синтетического пути включают флаг явно в фикстуре;
реальные E2E и новые тесты запускаются без него.

На GET `/api/stand/state` выполняется идемпотентное исправление ошибочных флагов
под блокировкой строки доски. Флаг снимается только без DEMO-истории: проверяются
части и хеши прихода, отправки, выплата/возмещение, связанные банковские поступления,
транзакции пачки и журнал. Исправление пишет событие, увеличивает версию;
устаревший PUT получает 409. При наличии истории флаг и деньги сохраняются,
в карточке видно предупреждение; автоматическое продолжение/закрытие запрещено.

Кошелёк фактического прихода брокера можно выбрать и при предоплате. В опциях
используются полный адрес и существующая дедупликация реестра. Карточка ожидания
показывает кошелёк брокера, а не источник оплаты IPPS. Новый атомарный API
`POST /api/stand/incoming/wallet` проверяет роль, версию доски, этап ожидания,
активный TRC-20 кошелёк реестра и отсутствие подтверждённых частей прихода.
Защита общего PUT не ослаблена. Кошелёк меняется для всей ожидающей пачки;
снимок плательщика IPPS и проведённая оплата сохраняются. Проверка хеша сверяет
новый адрес получателя; после первой подтверждённой части смена запрещена.
Возмещение идёт с фактического кошелька на кошелёк оплаты: одинаковые адреса
закрываются автоматически, разные требуют проверенного хеша.
