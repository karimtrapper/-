# design-gate · машинная инвентаризация до правок

Локальный стенд из текущего worktree, роль Karim, отдельная SQLite-база без рабочих сделок. Скилл `design-gate inventory`, фактически вычисленные стили видимых элементов. У каждого отчёта есть JSON и Markdown; оба размера 375/1280 сняты без BLOCKED. Инвентаризация не выдаёт PASS/FAIL и не заменяет `check` перед сдачей.

Количество вариантов кнопок — по сочетанию фон/рамка/радиус/шрифт среди видимых кнопок. `upper` — число элементов с `text-transform: uppercase`. Пустая локальная база ограничивает проверку динамических строк, деталей и статусов; их исходный код перечислен в [ручной инвентаризации](inventory.md).
