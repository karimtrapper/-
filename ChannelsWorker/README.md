# Справочник переписок для рабочего задачника

1. В сервисе CalcCRM задайте `STAND_MODE=0`, `TASKS_ENABLED=1` и `TASKS_CHANNEL_SYNC_ENABLED=1`.
2. Задайте новый случайный `TASKS_CHANNEL_SYNC_KEY` в CalcCRM и в ChannelsWorker. Для этого ключа доступна запись метаданных в `POST /api/stand/channels/catalog-sync`.
3. В том же ChannelsWorker задайте `TASKS_CHANNEL_SYNC_ENABLED=1`, `TASKS_CHANNEL_SYNC_BASE_URL` с HTTPS-адресом CalcCRM и `SYNC_LOOP_INTERVAL` в секундах, например `300`. Используйте существующие авторизованные подключения нужных рабочих аккаунтов. Для Bitrix укажите `SYNC_BITRIX_WEBHOOK`.
4. Перезапустите существующий ChannelsWorker после смены назначения. Сессия Telegram должна использоваться одним процессом.

В каждом цикле воркер получает список доступных чатов через настроенные источники и обновляет их ID, названия и время активности. Новый чат появится в поиске задачника после следующей синхронизации и обновления страницы. Ранее записанные привязки доступны при пустой или частичной выдаче источника.

В этом режиме воркер отправляет записи через HTTPS без перенаправлений, а функции чтения истории и экспорта переписки отключены. Раздельные ключи для рабочего каталога и стенда управляются независимо.
